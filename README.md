## 📖 项目简介

本项目深度萃取并精读了 2025-2026 年收录于《北京电影学院学报》《当代电影》等顶级核心期刊以及浙江传媒学院学者的 **16 篇重要学术论文**。
针对学术论述与应试写作场景，提炼了：
- **核心论点**：一句话亮明学界前沿论断
- **理论范畴**：权威学术概念与前沿术语体系
- **分层论证脉络**：分章论证逻辑与推导骨架
- **背诵金句库**：兼具理论厚度与表达亮点的学术原句（支持一键复制）
- **案例片目库**：经典与新锐电影文本互证
- **答题锦囊（5大标准模板）**：针对高频考题（AIGC、微短剧、新主流共同体美学、东方传统双创、影像本体危机）提供即抄即用的完整论述大纲

## 💡 论述答题锦囊（5 大高频题型模板）

1. **题型一【数智视听】**：论人工智能（AIGC）对影视艺术生产、美学范式与创作者主体性的重构（刘捷 + 茹纪晓 + 徐皓月）
2. **题型二【后电影与微短剧】**：论微短剧的兴起对传统电影视听叙事与美学格局的冲击与启示（蔡晓芳 + 方兆力 + 王一川）
3. **题型三【主流大片与共同体】**：论新时代中国新主流大片的美学演进、崇高重塑与价值建构（饶曙光 + 范志忠 + 李镇）
4. **题型四【东方诗学与传统双创】**：论中华优秀传统文化的创造性转化与当代东方电影诗学建构（高凡 + 刘强 + 李镇 + 陈亦水）
5. **题型五【影像本体与作者理论】**：论数字与数据库时代电影“作者论”与影像本体论的危机与重构（李瑞华 + 刘捷 + 南野）

## 💻 本地运行与部署方式

除在线访问 GitHub Pages 外，本仓库为纯静态原生 Web 应用，零外部黑盒依赖：

### 1. 本地双击秒开
直接双击打开 `index.html`，即可在任何现代浏览器中畅享完整交互与检索体验。

### 2. 本地局域网服务器
若需要在同一 Wi-Fi 下让手机/平板与电脑联动同步，双击运行 `启动网站.bat`，或在终端执行：
```bash
python server.py
```
